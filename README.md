# 다른 곳의 하루

12개 국가·지역의 자료를 바탕으로 구성한 중학교 도덕 수업용 브라우저 시뮬레이션.

## 실행

`python -m http.server 4173 --directory dist --bind 127.0.0.1`

브라우저에서 http://127.0.0.1:4173 을 엽니다. 별도 빌드가 없는 HTML/CSS/JavaScript입니다.

## 범위

- 12개 시나리오, 각 3개 장면과 2가지 선택 및 서로 다른 결과.
- 지역 무작위 배정(현재 브라우저에서 미완료한 사례 우선), 주제별 목록과 직접 배정.
- 개인 성찰 → 질문 개선 → 외부 AI용 프롬프트 복사 → 원문 검토 → 8항목 해결 계획.
- 자동 로컬 저장, 이어하기, 텍스트 내려받기, 인쇄/PDF.
- 실제 AI 호출, 학생 계정, 교사 서버 수집, 기기 간 배정 동기화는 없음.

## 근거와 교육적 설정

각 사례에 출처와 시점을 명시했습니다. 인물·소망·장면·선택·결과는 교육용 가정입니다. 실제 인물의 증언, 통계적 예측, 기관의 승인 자료가 아닙니다. 자료의 세부 출처는 dist/scenarios.js 및 앱 안의 출처 링크에 있습니다.

수업 전 원문과 정세의 변화를 확인하세요. 개인의 선택으로 구조적 문제가 해결되는 것처럼 표현하거나 학생에게 위험한 행동을 지시하지 않습니다. 선택에 점수·생존률·사망 결말을 부여하지 않습니다.

검증: `node validate.cjs`

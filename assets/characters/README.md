# 캐릭터 그림

캐릭터 그림을 이 폴더에 `<id>.webp` 이름으로 넣으면 앱이 자동으로 보여 줍니다. 그림이 없으면 주제 색 위에 이름 첫 글자가 나옵니다.

- 비율: 세로 3:4 (예: 900×1200)
- 파일 이름: tuvalu, pakistan, bangladesh, somalia, gaza, haiti, ghana, sudan, rohingya, afghanistan, congo, qatar (+ `.webp`)
- 실존 인물 사진이나 출처가 불분명한 그림은 쓰지 마세요. 직접 그리거나 사용 허락을 받은 그림, 또는 AI로 만든 가상 인물 그림을 쓰세요.

# 디자인 참고 분석: 국제앰네스티 「불편실험」

- 대상: https://act.amnesty.or.kr/NoHate/ (2026-11-09 확인)
- 방법: Craft Anything 클린룸 캡처(방문자에게 보이는 화면·측정값만, 코드는 읽지 않음) + 브라우저에서 방문자로 직접 진행
- 원칙: **연출 방식만** 가져온다. 로고·사진·영상·문구·노란색은 쓰지 않는다. '불편합니다' 버튼 같은 반응 방식도 가져오지 않는다. 우리 앱은 장면마다 선택지를 고르는 구조를 유지한다.

## 측정된 디자인 값 (1440px 기준)

| 항목 | 값 |
|---|---|
| 배경 | 거의 전부 `#000000` (59곳) |
| 강조색 | 노랑 1색 `#ffff00` (제목 상자, 핵심 버튼, 라벨) |
| 글자색 | 흰색 `#ffffff`, 보조 회색 `#b3b3b3`, 어두운 회색 `#525252` |
| 글꼴 | 픽셀 글꼴 하나(둥근모, DungGeunMo), 굵기 300 하나 |
| 글자 크기 | 본문 24px(휴대폰 20px), 표제 64px, 작은 글 14~18px |
| 모서리 | 둥근 모서리 없음 (radius 0) |
| 그림자 | 없음 |
| 간격 | 12px 단위가 대부분, 큰 구획 96px |

## 화면 흐름과 연출

1. **시작 화면**: 화면 가운데에 강조색으로 채운 큰 상자 하나. 안쪽에 겹선 테두리(이중 사각형), 큰 픽셀 제목, 그 아래 작은 영문 부제. 상자 아래에 설명 세 줄과 굵은 한 줄 지시문, 흰 테두리만 있는 사각 버튼 `START >`. 휴대폰에서는 버튼 밑에 `Press <START> button to continue` 같은 게임식 안내가 붙는다.
2. **장면 화면**: 영상이 화면을 꽉 채우고, 그 위에 HUD처럼 작은 검은 상자들이 떠 있다.
   - 왼쪽 위: 지시문 + 얇은 진행 막대 + 퍼센트(25%, 50%…).
   - 그 옆: 작은 사각 버튼 묶음(속도 1x·1.2x·1.5x·2x).
   - 왼쪽 아래: 대사 자막을 검은 띠 위 흰 글씨로.
   - 오른쪽 아래: 강조색으로 채운 큰 행동 버튼. 누르면 흰색으로 반전되고, 그 위에 강조색 한 줄 피드백("…기록되었습니다.")이 뜬다.
3. **장면 사이 화면**: 검은 화면 가운데에 픽셀로 그린 팔각형 안의 큰 숫자 카운트다운(3→2→1), 아래에 강조색 한 줄 + 흰색 두 줄 안내.
4. **결과 화면**: 위에 작은 강조색 영문 라벨(`COMMENTARY`, `RESULT`), 큰 흰 글씨 문장이 **타자기처럼 한 글자씩** 나오고 끝에 깜빡이는 강조색 커서. 결과 한 줄은 강조색 띠 위에 검은 글씨로 크게 보여 준다. 아래에 화면 썸네일 두 장과 설명, 테두리 사각 버튼 두 개(`< 다시 보기`, `이유 알아보기 >`). 왼쪽 위에 작은 제목, 왼쪽 아래에 `<Scroll down> to continue ↓`.

## 우리 앱이 가져올 원리

- **게임 화면처럼**: 카드·그림자·둥근 모서리·그라디언트 없이 검정 바탕 + 강조색 한 가지 + 흰 글씨. "AI가 만든 웹페이지" 느낌을 지우는 핵심이다.
- **한 화면에 한 가지 일**: 장면 하나, 질문 하나, 선택 하나. 설명 상자를 여러 개 쌓지 않는다.
- **HUD식 정보 배치**: 진행 상황(아침·낮·저녁, 1/3)은 구석의 작은 상자로, 장면 본문은 가운데 크게.
- **선택 → 즉시 반응**: 고른 선택지는 색이 반전되고, 결과는 타자기 효과로 한 글자씩 나온다.
- **장면 사이 쉼표**: 다음 장면으로 넘어갈 때 카운트다운·시간 전환 화면을 짧게 넣는다.
- **라벨은 작은 영문 대문자 + 강조색**: SCENE 01, RESULT, BEYOND CHOICE 같은 구획 표시.
- **버튼은 두 종류뿐**: 강조색으로 채운 주 버튼, 흰 테두리 사각 보조 버튼. 꺾쇠 `>`로 방향을 표시한다.

## 주의할 점

- 픽셀 글꼴은 긴 한국어 본문에서 읽기 어렵다. 중학생이 장면 본문을 오래 읽어야 하므로 제목·라벨·버튼에는 픽셀 글꼴, 본문에는 읽기 쉬운 픽셀풍 글꼴(예: Galmuri, SIL OFL) 또는 일반 고딕을 쓰는 방안을 검토한다.
- 참고 사이트의 노란색과 검정 조합은 쓰지 않는다. 강조색은 따로 정한다.
- 타자기 효과는 `prefers-reduced-motion`이면 끄고, 클릭하면 바로 전체가 보이게 한다.
